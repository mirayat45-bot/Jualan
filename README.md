# BOSS Sticker Kutoarjo — Website Resmi

Website profesional untuk BOSS Sticker Kutoarjo. Dibangun dengan Next.js 15, TypeScript, Tailwind CSS, dan Framer Motion.

## Tech Stack

- **Next.js 15** — App Router
- **TypeScript** — Type safety
- **Tailwind CSS** — Utility-first styling
- **Framer Motion** — Animasi halus
- **Lucide React** — Icon library

## Cara Menjalankan

```bash
# 1. Install dependencies
npm install

# 2. Jalankan development server
npm run dev

# 3. Buka browser
# http://localhost:3000
```

## Deploy ke Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

Atau langsung connect repo ke [vercel.com](https://vercel.com) untuk auto-deploy.

## Struktur Folder

```
src/
├── app/
│   ├── page.tsx          # Halaman utama
│   ├── layout.tsx        # Root layout + metadata SEO
│   └── globals.css       # Global styles + CSS variables
└── components/
    ├── AnimatedBackground.tsx  # Canvas digital network
    ├── Navbar.tsx              # Sticky glass navbar
    ├── Hero.tsx                # Hero + counter animasi
    ├── About.tsx               # Tentang kami + stats
    ├── Features.tsx            # Keunggulan (grid 6 card)
    ├── Services.tsx            # Layanan (grid 6 card)
    ├── Gallery.tsx             # Galeri + lightbox
    ├── Testimonials.tsx        # Slider testimoni otomatis
    ├── Location.tsx            # Jam buka + Google Maps
    ├── CTA.tsx                 # Call to action akhir
    └── Footer.tsx              # Footer lengkap
```
